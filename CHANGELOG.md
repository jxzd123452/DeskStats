# Changelog

## 1.0.0

First release.

### English

- Overview bento for CPU, memory, GPU, disks, network, battery, temperatures, and the host.
- Process list with search, sort, and a confirmation before ending a process.
- Detail pages for CPU, memory, GPU, disks, and network.
- Dark, light, and system themes. English and Simplified Chinese.
- Tray icon, pause, and close-to-tray. Sampling slows down only when every window is hidden.
- Desktop widgets for CPU, memory, GPU, network, disks, and sensors. Frameless, draggable, always-on-top or pinned to the desktop, with opacity, click-through, and remembered placement. One shared sampler.
- Threshold alerts for CPU, memory, GPU, temperature, disk free space, and low battery. Hold time, cooldown, and hysteresis. Native notifications and an in-app history.
- Optional NVIDIA readings through NVML. Demo mode for screenshots.

Screenshots: [English](README.md#screenshots) · [中文](README.zh-CN.md#截图)

Installers from this tag are **not code-signed**. Windows SmartScreen and macOS Gatekeeper will warn. On Linux, confirm the local package. Windows often has no CPU temperature; the card shows an em dash.

### 中文

- 总览 bento：CPU、内存、显卡、磁盘、网络、电池、温度和主机信息。
- 进程列表支持搜索、排序，结束进程前会确认。
- CPU、内存、显卡、磁盘、网络详情页。
- 深色、浅色、跟随系统。英文和简体中文。
- 托盘、暂停采样、关闭到托盘。只有所有窗口都隐藏时才降低采样。
- 桌面小组件：CPU、内存、显卡、网络、磁盘、传感器。无边框、可拖拽，可置顶或贴在桌面，可调不透明度和点击穿透，位置会记住。所有窗口共用一套采样。
- 阈值告警：CPU、内存、显卡、温度、磁盘剩余空间、低电量。含持续时间、冷却和回差。系统通知和应用内历史。
- 可选的 NVIDIA NVML 读数。演示模式用于截图。
